01 — Workflow

五步之内，说完即成文

主进程持有麦克风、热键、凭据、历史与文本注入；识别在云端完成，界面永远不被推理阻塞。

按住热键

默认 Windows / Linux 为 Ctrl+Shift+Space，macOS 为 Option。全部快捷键可在设置里改。

开口说话

只在按住期间录音，松手即停。麦克风可在设置中自由选择。

云端识别

音频送入你配置的 ASR 端点，流式返回，模型自带标点。

润色翻译

可选：用你自己的 LLM 清理口语、调整风格，或就地翻译选中文字。

输入并留存

结果直接注入光标所在应用，并保存到本机历史（90 天）。

02 — Features

把语音输入做成一种习惯

不打断心流的桌面原生体验：快捷键唤起、流式出字、就地润色，凭据与历史都留在本地。

按住说，松开写

全局 Push-to-Talk 热键，边说边出字的流式 HUD，标点由模型原生生成。说完的瞬间，文字已经落在光标处。

自带识别服务

内置 MiMo、通义千问、豆包 Ark、OpenAI 等预设，也可填任意 OpenAI 兼容的 Base URL、模型与 API Key。

可选 AI 润色与翻译

接入 OpenAI、DeepSeek、OpenRouter 或自定义端点，一键清理口语、调整文风；也能就地翻译并替换选中文字。

历史留在本机

最近 90 天的转写记录保存在本机用户目录，可搜索、复制、查看、删除，不上传任何云端账号。

桌面原生工作流

自定义全局热键、麦克风选择、状态 HUD、常驻胶囊、开机自启、更新检查，文字直接注入当前前台应用。

中英双语界面

应用语言可在设置中随时切换；Linux 侧提供 AppImage 与 Omarchy/Arch 包，并内置 Hyprland 集成工作流。

03 — Privacy

说清楚每一段数据去了哪

语音识别、润色、翻译走的是你配置的云端端点，设备上不做模型推理。每一项都有明确边界：

SCOPE 01

语音识别

录制的音频上传到你配置的云端 ASR 端点，返回转写文本。关闭其他功能后，这是唯一的网络出口。

SCOPE 02

文本润色

只发送识别出的最终文本——不是原始音频——到你配置的 LLM 提供商。

SCOPE 03

翻译替换

只把选中的文字发给该提供商，并用返回结果替换选区，不附带其他上下文。

SCOPE 04

历史与密钥

历史保存在应用本地用户数据目录；API Key 由主进程管理，绝不写入应用日志。

不需要润色和翻译时，可以直接关闭它们——芷若只保留语音识别一条网络链路。凭据与转写内容不出本机日志，你随时可以删掉全部历史。
04 — Under the Hood

克制的架构，经得起折腾的开源

Tauri 2 的 Rust 主进程掌管一切特权操作，渲染层只负责界面；MIT 许可，随便看、随便改。
