# lib/

通用工具函数目录。

## 文件

- `utils.ts` - `cn()`：合并 `className`（`clsx` + `tailwind-merge`）。
- `hotkey-utils.ts` - 快捷键工具：规范化、构建、格式化与校验 Accelerator，并内置系统保留键规则；修饰键按物理键 `code` 区分左右（右 Alt/Control/Shift 产出 `AltRight/ControlRight/ShiftRight` token，可单独作为 PTT 键；组合键中归一为普通修饰 token），Windows AltGr 的合成 Control 按键直接丢弃；F1-F24 与方向/标点 token 与 Rust `hotkey.rs` 解析器逐字对齐（含"纯修饰键只能是单个裸修饰键"预校验），未识别的键返回原始键以触发 `unsupported` 提示而非静默丢弃。
- `tauri-api.ts` - Tauri IPC 桥，挂载为 `window.electronAPI`（与 Electron preload 同形）；`setConfig` 返回 `SetConfigResult`（持久化配置 + `hotkeyRolledBack` 回滚标记），`setHotkeyCaptureActive` 通知 Rust 快捷键录制态守卫，`setOverlaySize` 把 overlay 窗口缩到 HUD 胶囊内容尺寸（`set_overlay_size`，Rust 侧钳制尺寸合法性），`setOverlayPosition(x, y, capsule?)` 把拖拽后的物理像素坐标交给 Rust 做贴边吸附、工作区钳制与持久化（`x`/`y` 为 `null` 表示重置为底部居中默认位；可选 `capsule: { width, height }` 为可见胶囊实际尺寸、逻辑像素，Rust 据此做**半隐贴边**吸附——胶囊中线压在屏幕边上、一半嵌入屏幕（0.5.7 起距离带符号：任一边**接触或溢出**均吸附，拖过头不再被 48px 阈值拒吸），缺省回退按窗口外框吸附的旧行为；**返回值** `Promise<OverlayEdge | null>`——`'left' | 'right' | 'top' | 'bottom'` 表示本次落位已贴边吸附（docked，待机胶囊收成紧凑形态），`null` 表示距所有边都超阈值仅钳制落位或复位（保持全形），Rust 同时把该结果持久化到 `app.overlayDocked`，HUD 挂载时经 `getConfig` 读回以跨重启恢复形态）。鼠标中键 PTT 设置（`mouse.middleClickPtt`）随 `setConfig` 流程下发、无独立桥方法；hover 穿透（0.5.15）经 `setOverlayHitRect(rect | null)` 推送胶囊可见矩形（**逻辑 px、相对窗口客户区原点**，`getBoundingClientRect` 口径；`null` = 胶囊消失 → 窗口恒穿透；仅 overlay / session 两窗可调）与 `setOverlayHoverGrab(grabbed)` 交互锁（手势 / latch / 录音在途锁定不穿透）——ignore 标志由 Rust `mouse.rs` 悬停机制唯一拥有，HUD 不再直接调用 `setIgnoreMouseEvents`；悬浮胶囊显隐由托盘菜单直接控制（`app.overlayVisible`），`onOverlayUpdate` 的 `OverlayStatus` 含常驻待机态 `idle`。
- `logger.ts` - 渲染进程日志初始化：仅转发 `console.warn` / `console.error` 与未捕获错误到主进程日志；`console.log` / `console.info` / `console.debug` 保留在 devtools 输出，不再写入日志文件。
- `stats.ts` - `computeStats()`：合并 Rust 侧独立持久化统计（`StoredDictationStats`，`get_stats` 取数，删除/裁剪历史不影响）与历史实时聚合，计算今日/近 7 天/累计/活跃天数/峰值日；**`stored` 存在时全部字段取自 `stored`**（累计读 `totals`，今日读 `daily[todayKey]`，近 N 天按日历日求和 `daily`），故删除/清空历史后数字不缩水；仅 `stored` 缺失（老版本回退 / `get_stats` 失败）才整体降级为纯历史聚合。`countCharacters()` 按 **Unicode 码点** 剔除空白计数（`Array.from` 拆码点，emoji 计 1），与 Rust `stats.rs` `count_characters` 逐字对齐。`stats.test.ts` 为其回归测试：`countCharacters` 用例是 Rust 单测 `count_characters_matches_frontend_whitespace_rule` 的 JS 镜像（含 emoji 用例），另有 `computeStats` 删除历史后输出不变的锁定用例，两侧口径必须同步改。
- `overlayDrag.ts` - HUD 胶囊「点按切换 / 按住说话 / 拖拽」状态机的纯函数实现（0.5.3 重设计）。会话语义：**轻点 = latch 切换**（松手后录音持续，再点一下 stop 识别）、**按住满 `HOLD_LATCH_MAX_MS` = PTT**、**拖拽 = 只移窗且从不启动会话**。负责 pending → dragging / holding → end 的阈值判定、pointerId 过滤、**手势歧义消除前不启动会话**、双击复位（第 2 击静默 cancel-session）、以及 pointercancel / blur / 看门狗只作用于活跃手势并**豁免已松手的 latched 会话**；另含 `isSilenceAutoStopDue` 纯函数（latched 会话静音自动停止判定，`SILENCE_AUTO_STOP_MS` / `SILENCE_LEVEL_THRESHOLD`）、**贴边紧凑形态词汇** `isOverlayEdge`（docked 判定，invoke 边界脏值一律按「未吸附」处理）与 `DOCK_COMPACT_PX = 32` / `DOCK_TRANSLATE`（紧凑胶囊边长 + 四边贴齐位移类，±16px = 边长/2，把胶囊外缘压到窗口中线 = 屏幕边、整只屏内）。0.5.15 增 hover 穿透纯函数：`isHoverGrabActive`（交互锁判定——pending / holding / dragging / latched / 录音中锁定窗口不穿透，回 idle 放开）与 `toOverlayHitRect`（DOMRect → `set_overlay_hit_rect` 载荷规范化：显式复制成普通对象（DOMRect getter 不可序列化）、脏值返回 `null` 且调用方跳过推送而非清空热区）。**硬不变量（模块头 REGRESSION WARNING）**：窗口几何在任何手势进行中（pending / holding / dragging）与会话存活期间不可变——命令词汇里**没有任何 resize / 重锚定命令**（0.5.2 的「拖不动 + 闪烁」与 0.5.3 的「按住骤停」都源于手势内 resize 打断指针）。只返回命令描述，不访问 DOM 或 Tauri API。`overlayDrag.test.ts` 覆盖上述全部语义（含「pointerdown 不得启动会话」「拖拽不得 start/cancel 会话」「latched 不被 cancel/blur/看门狗误杀」「window geometry invariant」等回归锁定用例，以及 0.5.7 溢出吸附契约的渲染层一半：拖拽原样发出未钳制坐标、含溢出负坐标，吸附/钳制判定一律留给 Rust）。
- `useStatFormatters.ts` - 统一的数字 / 时长 / 峰值日格式化 Hook，供主页与统计组件共用。
- `useTheme.ts` - 界面主题与强调色：三主题 `scifi`（科幻，暗）/ `fresh`（清新，亮）/ `business`（商务，亮），强调色含 `auto`（跟随主题主色）与 6 个显式色（覆盖主题主色系）。**模块级共享 store**（`useSyncExternalStore` 订阅）——侧栏与设置页同时挂载 `useTheme`，各自 `useState` 会失同步，故状态收敛到模块级；`initThemeStore()` 由 `main.tsx` 对**所有窗口**入口调用（overlay/hub/session 同步吃主题，不只主窗）；持久化到 `localStorage`（老 `light`/`dark` 迁移后落盘；强调色键 `vk-accent-v2`，旧键被隐式默认值污染不迁移），同步 `<html>` 的 `data-theme` 与 `.dark` 类（仅科幻挂 `.dark`），首帧由 `index.html` 预置脚本按同一口径先行渲染避免闪白。纯函数 `resolveTheme` / `resolveAccent` / `isDarkTheme`、`THEME_OPTIONS` 及「三主题色板 vs `@theme inline` 变量完备性」由 `useTheme.test.ts` 锁定。
- `segment-display.ts` - 七段数码管段位映射：`getSegments(char)` 返回点亮段位集合（`a` 上 / `b` 右上 / `c` 右下 / `d` 下 / `e` 左下 / `f` 左上 / `g` 中），`isDotChar` 识别小数点 / 冒号点阵单元。渲染见 `components/SegmentDisplay.tsx`，回归测试 `segment-display.test.ts`。
- `changelog.ts` - 更新日志解析与 Markdown 渲染：将仓库 `CHANGELOG.md` 按版本分节，默认过滤掉早于 `0.5.0` 的版本（语义化版本比较，避免 `0.10.0` 被字符串比较误滤）；`renderMarkdown` 将正文渲染为 HTML，覆盖 CHANGELOG 实际使用的标题、列表、粗体、行内/围栏代码、链接、分隔线等语法；注入防线上**全文先 HTML 转义（含引号）再解析标记**，围栏语言串字符集白名单进 class 属性，链接 href 仅放行 http(s)，回归用例见 `changelog.test.ts`（正文原始 HTML / 引号注入 / `javascript:` 链接 / 恶意语言串）。
