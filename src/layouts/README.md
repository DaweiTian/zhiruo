# layouts/

应用布局容器目录，定义应用的整体结构和导航框架。

## 文件

### `MainLayout.tsx`

应用主布局组件，提供：

- **自定义标题栏** - 通过 `TitleBar` 组件提供统一的窗口拖拽与窗口控制按钮，替代系统原生标题栏
- **左侧边栏** - 包含导航菜单（Home, Settings, History）与底部「版本号 + 主题切换」区；支持折叠为贴边窄条，状态持久化到 `localStorage`
  - 折叠态宽度 48px，导航菜单显示为图标按钮并保留 hover/active 反馈与 title tooltip
  - 底部版本号以七段数码管（`SegmentDisplay`，暗底 LED 模块 + 主题色辉光）呈现，点击打开更新日志；右侧为三主题（科幻 / 清新 / 商务）图标切换，折叠态整块隐藏
  - 折叠/展开按钮位于侧栏右缘中部，独立于侧栏容器以避免被主内容区遮挡或裁剪；由于侧栏与主内容区 gutter 同色（`bg-sidebar`），用户感知的侧栏右边界实际为主内容卡片左边界，因此按钮向右额外偏移 `0.75rem`（主内容 `p-3` 宽度），使按钮圆心与卡片左边界对齐，展开/折叠两态均保持跨线位置
- **右侧内容区** - 渲染当前路由对应的页面内容
- **路由导航** - 基于 hash 路由的页面切换逻辑

所有页面组件通过 `MainLayout` 包裹，确保统一的视觉和交互体验。
